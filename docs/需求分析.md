# 万能视频下载网站 - 需求分析文档

## 1. 项目背景

用户有从各平台下载保存视频到本地的需求，但很多平台不支持直接下载、或限制较多（清晰度限制、不支持批量下载等）。本项目旨在提供一个统一的、跨平台的万能视频下载工具网站。

## 2. 目标用户

- 需要下载在线视频到本地保存的个人用户
- 需要批量采集视频素材的内容创作者
- 需要在移动端随时下载视频的用户
- 想快速了解长视频内容、提升学习效率的用户
- 手里有本地视频、但视频没有公开链接的用户（本地录屏、会议录像、已下载好的课程、手机拍摄素材等），同样需要生成字幕并做 AI 分析

## 3. 核心功能需求

### 3.1 视频解析（P0）
- 用户粘贴视频链接，系统自动解析视频信息
- 展示视频标题、缩略图、时长、上传者、平台来源
- 列出所有可用的格式和清晰度选项

### 3.2 视频下载（P0）
- 用户选择清晰度/格式后，点击下载
- 支持两种下载模式：
  - **直链模式**：解析出视频直链，浏览器直接下载（不占服务器资源）
  - **服务端代理模式**：服务端下载后提供下载链接（兼容有防盗链的平台）
- 自动选择最优下载模式

### 3.3 多平台支持（P0）
- 基于 yt-dlp 开源项目，支持 1800+ 平台
- 包括但不限于：YouTube、Bilibili、抖音、TikTok、Twitter/X、Instagram 等

### 3.4 移动端适配（P1）
- 响应式设计，手机浏览器也能正常使用
- 触屏友好的交互设计

### 3.5 付费功能（P2，预留）
- 免费版：基础下载功能，有次数或清晰度限制
- VIP 版：批量下载、4K 画质、字幕下载、无广告、优先队列

### 3.6 AI 视频总结（P1，已实现）
- 用户在视频解析结果页点击「AI 总结」按钮，触发 AI 分析
- **总结摘要**：AI 自动生成视频概述、内容大纲、核心知识要点、一句话总结，使用 @tailwindcss/typography 精美排版
- **字幕文本**：展示带时间戳的完整字幕列表，支持展开/收起，支持下载字幕文件（SRT / VTT / TXT 三种格式）
- **思维导图**：AI 生成结构化内容，前端渲染为可交互的思维导图，支持全屏展示，支持下载高清 PNG（4K+）和 SVG 矢量图
- **AI 问答**：用户可针对视频内容提问，AI 基于字幕上下文回答，支持多轮对话
- 字幕获取策略：优先提取平台自带字幕（人工字幕 > 自动字幕），B 站通过专用 API 获取 CC 字幕
- AI 能力：接入 DeepSeek 大模型，流式输出（SSE），实时展示生成过程

### 3.7 扩展功能（P2，预留）
- 字幕翻译
- 下载历史记录
- 批量下载

### 3.8 本地视频上传解析（P1，已实现）
- 在首页顶部切换视频来源：「在线链接」或「本地上传」，原有链接解析流程不受影响
- 用户拖拽或选择本地视频文件上传，服务端依次完成：ffprobe 校验（确认确实是视频、含音轨、时长合规）→ ffmpeg 提取音频（16kHz 单声道 WAV）→ faster-whisper 语音识别，生成带时间戳的字幕
- **产出的字幕结构与在线视频完全一致**，因此 3.6 的总结摘要、字幕文本、思维导图、AI 问答以及字幕下载（SRT / VTT / TXT）全部原样复用，交互与在线视频没有差别
- 字幕来源标注为「AI 识别字幕」，与平台自带的人工/自动字幕区分开
- **处理状态展示**：上传进度、校验、提取音频、转写中、完成/失败逐步可见，失败给出明确的中文提示；任务可随时删除
- **结果本地持久化**：字幕与 AI 结果缓存在浏览器 localStorage（按账号隔离、2 小时过期），刷新页面或退出重新登录都能恢复，且恢复不重复扣除 AI 总结次数
- 语音识别使用 faster-whisper，完全在本机运行，无需额外 API Key，音频不出本机
- **用户价值**：本地录屏、会议录像、下载好的课程、手机拍摄的素材等没有公开链接的视频，也能用上整套「字幕 → 总结 → 导图 → 问答」的能力

**支持格式与限制**
- 支持 23 种常见容器格式：MP4 / MOV / MKV / AVI / WebM / FLV / WMV / TS 等
- 单个文件最大 500MB
- 视频时长最长 60 分钟
- 必须登录后使用；同一账号同时只允许 1 个处理中的任务
- 管理员账号（通过 `ADMIN_EMAILS` 环境变量指定）不受每日总结次数、并发数、视频时长限制；文件大小是**放宽**到 5GB（`ADMIN_MAX_FILE_SIZE_MB` 可调）而非取消，超出仍会被拦截

**第一版明确不做**
- 视频库
- 服务端上传历史（结果只留在浏览器本地，换设备看不到）
- 批量上传
- 视频剪辑
- 多用户共享
- 高级视频理解（如说话人分离、画面内容识别）

## 4. 非功能需求

- **性能**：视频解析响应时间 < 10s
- **性能（本地视频转写）**：CPU 环境下约 0.4x 实时，60 分钟视频约需 25 分钟；有 NVIDIA 显卡时设 `WHISPER_DEVICE=cuda` 可提速 5-10 倍。转写任务串行执行，多人同时上传需排队
- **可用性**：简洁易用的 UI，新用户无需学习即可使用
- **安全性**：不存储用户数据，临时文件定期清理
- **隐私（本地视频）**：不长期保存用户视频——视频文件在提取音频后立即删除，音频在转写完成后立即删除，服务端只保留文字结果且 2 小时后过期清理；音频不上传任何第三方服务
- **兼容性**：支持 Chrome、Firefox、Safari、移动端浏览器

## 5. 技术约束

- 以 Python 为主要技术栈
- 核心下载能力依赖 yt-dlp 开源项目
- 不使用数据库，保持轻量
- 前后端分离架构
- 本地视频的音频提取依赖 ffmpeg / ffprobe（需在 PATH 中，项目自带 `tools/ffmpeg/`）
- 语音识别依赖 faster-whisper（本地运行，首次运行会自动下载模型；国内网络可用 `HF_ENDPOINT` 镜像加速）
- 本地视频的任务状态存于内存，不支持多进程部署（`--workers > 1` 时上传与查状态可能落在不同进程），当前按单进程部署
