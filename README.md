# AI 万能视频下载总结器（SaveAny）

> 本项目由 **橙宝** 基于开源项目二次开发，在原版视频解析下载能力之上，新增了本地视频上传解析（语音识别自动生成字幕）等功能。
>
> 技术栈：Vue 3 + FastAPI + yt-dlp + DeepSeek + Stripe + faster-whisper



## 一、项目介绍

SaveAny 是一个 AI 驱动的万能视频下载总结器：输入一个视频链接，工具自动解析视频信息，支持从 B 站、YouTube、抖音等 **1800+** 平台下载视频；除了在线链接，还支持 **上传本地视频**（录屏、会议录像、下载好的课程等），自动识别语音生成字幕。两种来源都能享受 **AI 视频总结**（摘要 + 思维导图 + 问答），并集成了 **用户认证** 和 **Stripe 国际支付** 能力。

**一个链接搞定视频下载 + AI 总结，学习效率翻倍！**

⚠️ 合规使用声明：本项目仅用于技术学习和研究目的，请用户仅下载自己拥有版权或已获得合法授权的内容（如备份自己上传的视频、下载公开授权的免版权素材等）。用户应自行遵守所在地区的法律法规及各平台的服务条款，开发者不对用户的使用行为承担任何法律责任。



### 8 大核心能力

1）多平台视频解析和下载：基于 yt-dlp 支持 1800+ 网站，涵盖 B 站、YouTube、抖音等主流平台，提供多种清晰度和格式供用户选择。针对抖音等特殊平台，开发了专用解析模块，无需用户提供 Cookie 即可获取无水印视频。

2）本地视频上传解析：没有公开链接的视频也能用，支持直接上传本地视频文件，自动识别语音生成字幕。后端先用 ffprobe 校验文件、ffmpeg 提取音频，再用 faster-whisper 本地转写，产出的字幕结构与在线视频完全一致，因此 AI 总结、思维导图、问答、字幕导出全部原样复用。支持 MP4、MOV、MKV、AVI、WebM、FLV 等 23 种容器格式，默认限制单个文件 500MB、时长 60 分钟，需登录后使用。语音识别在本机完成，不依赖第三方 API，视频和音频在转写完成后立即删除，只保留文字结果。

3）AI 视频总结摘要：自动提取字幕并调用 DeepSeek 大模型进行内容分析，流式输出视频的总结摘要，按章节生成带时间戳的内容大纲，Markdown 格式排版精美，帮助用户快速了解视频核心要点。

4）AI 生成思维导图：基于视频内容自动生成交互式思维导图，支持全屏展示、缩放拖拽、导出高清 PNG 和 SVG 格式图片。

5）AI 视频问答：用户可以基于视频内容进行自由问答，AI 根据字幕文本给出针对性的回答，并在引用具体内容时标注时间点（如【03:25】），方便溯源核对。

6）字幕导出与翻译：支持下载 SRT、VTT、TXT 等多种格式的字幕文件，并可一键将字幕翻译为中文或英文，方便用户自行整理和学习。

7）用户注册登录 + 会员权限：支持邮箱 + 密码注册登录，基于 JWT 实现无状态认证。免费用户每天可使用 3 次 AI 总结，VIP 会员不限次数。

8）Stripe 国际支付：集成 Stripe 国际支付平台，支持信用卡等多种支付方式，用户可一键开通 VIP 会员，解锁无限 AI 总结次数。



## 二、技术要点

- 多平台视频解析下载：yt-dlp 封装与特定平台（抖音）适配
- 本地视频处理：ffprobe 校验 + ffmpeg 音频提取 + faster-whisper 本地语音识别
- AI 能力：DeepSeek 大模型实现视频总结、思维导图和问答
- 流式交互：基于 SSE 的流式数据传输
- 用户体系：JWT 无状态认证与权限控制
- 支付能力：Stripe 国际支付集成与 Webhook 回调
- 前端工程：Vue 3 + Vite，SEO 友好的页面结构



## 三、快速运行

> 详细的保姆级教程请参考 [保姆级本地运行指南](./docs/保姆级本地运行指南.md)



### 1. 前置条件

- Python >= 3.10
- Node.js >= 18
- ffmpeg（用于音视频合并，本地视频解析还会用到 ffprobe 校验和音频提取）
- 一个 [DeepSeek API Key](https://platform.deepseek.com/api_keys)（用于 AI 总结）
- faster-whisper（用于本地视频的语音识别，执行 `pip install -r requirements.txt` 时会自动安装，无需额外的 API Key）

> 首次使用本地视频上传解析时，faster-whisper 会自动下载语音识别模型（默认 base），需要联网，下载完成后即可离线使用。国内网络可在 `.env` 中配置 `HF_ENDPOINT=https://hf-mirror.com` 加速下载。

### 2. 启动后端

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env
# 编辑 .env 填入 DeepSeek API Key 等配置
python main.py
```

### 3. 启动前端

```bash
cd frontend
npm install
npm run dev
```

### 4. 访问使用

浏览器打开 http://localhost:5173 ，输入视频链接即可体验视频解析下载和 AI 总结功能。

更多配置细节（环境变量、Stripe 支付、常见问题等）请查看 [保姆级本地运行指南](./docs/保姆级本地运行指南.md)。
